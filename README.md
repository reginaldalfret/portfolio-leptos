## ⚡ Tech Stack & Features

- **Framework:** Leptos 0.7 (Client-Side Rendering)
- **Language:** Rust 1.99.1 (`wasm32-unknown-unknown`)
- **Bundler & Tooling:** Trunk 0.22.1 with WebAssembly code-splitting
- **Styling:** Tailwind CSS with Coral/Rust Orange obsidian theme (`#F97316`)
- **Key Modules:**
  - 30 Merged PRs showcase with reactive category filtering
  - Professional career history & 3 flagship hackathon victories
  - Skills matrix & professional certifications
  - Original resume PDF modal and direct downloads
  - Responsive liquid-glass obsidian command bar and dock

## 🚀 Development & Build

# Serve locally on port 8089 / 8088
