### 4. Prerequisites & Local Development

#### Prerequisites
- Rust 1.80+, target wasm32-unknown-unknown, trunk

#### Installation
```bash
git clone https://github.com/reginaldalfret/portfolio-leptos.git
cd Portfolio-Leptos
cargo fetch
```

#### Running Development Server
```bash
trunk serve
```

#### Production Build
```bash
trunk build --release
```

#### Running Test Suite
```bash
cargo test
```
